# Интерфейс

Ориентир — чат MAX: две колонки, спокойный тёмный мессенджер, минимум хрома. Пиксель-перфект копия бренда не требуется.
Тексты — на русском. Поведение экранов — в [бизнес-логике](./03-business-logic.md).

## Экраны

1. **Подключение** — по центру форма: `idInstance`, `apiTokenInstance`, кнопка «Подключиться». Пока запрос идёт, повтор недоступен. Ошибка — под формой, поля остаются доступны.
2. **Чаты** — слева список и форма номера, справа переписка выбранного чата. Справа сверху — имя/номер и «Выйти». Снизу — поле ввода и «Отправить».
3. **Нет выбранного чата** — справа подсказка создать или выбрать чат. Поле отправки скрыто или неактивно.
4. **Пустая переписка** — выбран чат, сообщений нет.
5. **Получение остановлено** — над перепиской показываем сообщение об ошибке и кнопку «Повторить получение».
   Если проблема в учетных данных, пользователь использует «Выйти» и подключается заново.

Адаптив: при ширине меньше `720px` список и переписка не обязаны быть рядом; сохраняй доступ с клавиатуры и видимый фокус.

## Компоновка (десктоп)

- Колонка чатов: ширина `320px`, фон `--color-sidebar`.
- Шапка чата: высота около `56px`.
- Область сообщений: скролл, старые сверху.
- Исходящие пузыри справа (`--color-bubble-out`), входящие слева (`--color-bubble-in`).
- Статус исходящего (`sending` / `accepted` / `failed` / `unknown`) мелким текстом у пузыря, не отдельным экраном.
- Для `failed` и `unknown` отдельной кнопки у пузыря нет. Неотправленный текст остаётся в поле сообщения;
  пользователь исправляет его при необходимости и повторно нажимает общую кнопку «Отправить».

## Проверка поля сообщения

- Пустое поле, в том числе после успешной отправки: обычная подсказка, без ошибки; «Отправить» неактивна.
- Если введены только пробелы или переносы строк: показываем «Введите текст сообщения.» и отмечаем поле как ошибочное.
- При превышении 4096 символов показываем ошибку длины. Некорректный текст не отправляем.
- После исправления текста или полной очистки поля ошибка исчезает.

## Подписи

| Место | Текст |
| --- | --- |
| Заголовок входа | Вход |
| Поля входа | idInstance, apiTokenInstance |
| Кнопка входа | Подключиться |
| Поле номера | Номер телефона |
| Кнопка чата | Создать чат |
| Поле сообщения | Сообщение |
| Отправка | Отправить |
| Выход | Выйти |
| Пустой список | Нет чатов. Укажите номер получателя. |
| Нет выбора | Выберите чат или создайте новый |
| Пустая переписка | Нет сообщений |
| `exist: false` | Не удалось найти доступный аккаунт по этому номеру. Возможно, его нет в Telegram или скрыт настройками приватности. |
| Не `authorized` | Инстанс не готов к работе. Проверьте авторизацию Telegram в кабинете GREEN-API. |
| `failed` | Не удалось отправить. Исправьте текст или повторите отправку. |
| `unknown` | Не удалось подтвердить отправку. Сообщение уже могло уйти — не отправляйте повторно, пока не убедитесь. |
| Сбой получения | Нет связи с очередью сообщений. Повторная попытка… |
| Получение остановлено | Получение сообщений остановлено. Проверьте подключение и повторите попытку. |
| Возобновление получения | Повторить получение |
| Кнопка без текста | Доступное имя через `aria-label` |

Не вставляй токен и полный URL запроса в эти строки.
