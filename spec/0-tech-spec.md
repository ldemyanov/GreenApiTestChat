# Техническое задание

Детали поведения, API и интерфейса: [бизнес-логика](./03-business-logic.md), [контракт GREEN-API](./04-green-api-contract.md), [интерфейс](./05-ui.md).

## Требования

1. Требуется разработать пользовательский интерфейс для отправки и получения сообщений в Telegram.
2. Требуется использовать сервис [GREEN-API](https://green-api.com/telegram).
3. Требуется реализовать отправку и получение только текстовых сообщений.
4. Требуется за прототип интерфейса взять внешний вид чата MAX.
5. Требуется реализовать интерфейс максимально простым, с минимальным набором функций.
6. Требуется отправку сообщений реализовать методом [SendMessage](https://green-api.com/telegram/docs/api/sending/SendMessage/).
7. Требуется получение сообщений реализовать методом, описанным в [документации HTTP API](https://green-api.com/telegram/docs/api/receiving/technology-http-api/).
8. Требуется использовать React.

## Ожидаемый результат

1. Пользователь входит на сайт чата и вводит свои учетные данные из системы GREEN-API: `idInstance` и `apiTokenInstance`.
2. Пользователь вводит номер телефона получателя и создает новый чат.
3. Пользователь вводит текстовое сообщение и отправляет его получателю в Telegram.
4. Пользователь отвечает на сообщение в мессенджере Telegram.
5. Пользователь видит ответ получателя в чате.
